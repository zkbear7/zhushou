# 考研备考 · 每日助手

一个面向安卓平板的考研备考日常提醒网页应用（PWA）。

## 功能

- **主页仪表盘**：考试倒计时 + 当前时段任务 + 今日完整时间表
- **可视化打卡统计**：今日完成率 + 7日趋势柱状图 + 连续打卡天数
- **任务打勾**：每项任务可勾选标记完成，自动保存
- **侧边抽屉**：11 个折叠面板（数学分级 / 做题流程 / 每日任务细化 / 828章节 / 英语 / 政治 / 肖1000三刷 / 进度节点 / 每周复盘指南 / 完整周计划 / 备考Tips）
- **浏览器通知**：6 个关键时间点自动弹窗提醒（09:00高数 / 单词 / 下午大块 / 单词 / 线代概率 / 19:25政治），通知偏好持久化（30天不重复弹）
- **阶段自动切换**：6月按日期安排 → 7-8月基础收尾 → 9月起二刷/分类真题/套卷
- **学6休1（周六休息）**：一二四=自控日，三五日=英语日，每天21:30收工；每天显示明天任务预告（明天休息则连下个学习日一起显示）
- **每周复盘**：周六休息日按"每日4问+每周5问+科目复盘"执行，做不完周五晚兜底
- **选填每日练**：每天20min·5-6题（880必抓选填/真题选填·每题≤4min）→对答案→标⭐→补技巧卡→隔天回看
- **理论课背单词**：周二13:30/周五10:00 理论课=复习昨天+背新40-50个（实验课不安排·至10.16最后一节课，之后恢复常规单词槽）
- **柔和简约设计**：暖白色调 + 莫兰迪色系 + 霞鹜文楷 Screen 字体

## 部署（GitHub Pages）

1. 在 GitHub 新建仓库，上传 `index.html`、`sw.js`、`manifest.json`
2. Settings → Pages → Source: main branch, root folder → Save
3. 访问 `https://你的用户名.github.io/仓库名/`
4. 安卓平板 Chrome 打开，点右上角菜单 → "添加到主屏幕"

## 通知权限

首次打开网页会请求通知权限，点"允许"即可接收定时提醒。
关闭横幅后 30 天内不会再次弹出。
