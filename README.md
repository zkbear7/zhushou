# 考研备考 · 每日助手

一个面向安卓平板的考研备考日常提醒网页应用（PWA）。

## 功能

- **主页仪表盘**：考试倒计时 + 当前时段任务 + 今日完整时间表
- **可视化打卡统计**：今日完成率 + 7日趋势柱状图 + 连续打卡天数
- **任务打勾**：每项任务可勾选标记完成，自动保存
- **侧边抽屉**：9 个折叠面板（数学分级 / 828章节 / 英语课+单词方法 / 政治路线 / 肖1000三刷 / 进度节点 / 三分化健身 / 完整周计划 / 备考Tips）
- **浏览器通知**：4 个关键时间点自动弹窗提醒（09:00 / 11:00健身日 / 14:00 / 20:00），通知偏好持久化（30天不重复弹）
- **阶段自动切换**：6月按日期安排 → 7月高数强化期 → 8月线代概率刷题 → 9月+秋季强化
- **学6休1 + 隔天健身**：三分化力量训练（推/拉/臀腿）+ 跑步机快走有氧
- **柔和简约设计**：暖白色调 + 莫兰迪色系 + 霞鹜文楷 Screen 字体

## 部署（GitHub Pages）

1. 在 GitHub 新建仓库，上传 `index.html`、`sw.js`、`manifest.json`
2. Settings → Pages → Source: main branch, root folder → Save
3. 访问 `https://你的用户名.github.io/仓库名/`
4. 安卓平板 Chrome 打开，点右上角菜单 → "添加到主屏幕"

## 通知权限

首次打开网页会请求通知权限，点"允许"即可接收定时提醒。
关闭横幅后 30 天内不会再次弹出。
